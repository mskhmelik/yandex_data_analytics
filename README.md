# Data Analyst Portfolio Projects

This repository contains a comprehensive collection of data analysis projects completed as part of a Data Analyst course. Each project demonstrates various aspects of data analysis, including data preprocessing, statistical analysis, hypothesis testing, machine learning, and business analytics.

## Portfolio Overview

This portfolio consists of 15 projects covering a wide range of data analysis topics and techniques:

- **Data Preprocessing & Cleaning**: Handling missing values, data type conversions, outlier detection
- **Statistical Analysis**: Hypothesis testing, A/B testing, statistical significance
- **Business Analytics**: Revenue analysis, customer behavior, market research
- **Machine Learning**: Classification models, clustering, churn prediction
- **Data Visualization**: Interactive charts, maps, dashboards
- **SQL & Databases**: Query optimization, data extraction, database analysis
- **Time Series Analysis**: Cohort analysis, retention, lifetime value
